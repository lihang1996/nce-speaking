# 实施计划、验证门槛与需求追踪

> 对应 PRD v2.5.7、75 项功能；云端读取时有 55 项实现 Tickets。本文的工程工作包不另外增加产品功能，也不把设计文档当成实现验收。

## 1. 交付顺序

先打通“资料装入 → 离线学习 → 真实到期复习 → 可信状态 → 备份恢复”，再接 AI。账号服务与本地规则可分别开发，但完整 M1 验收必须用注册登录后的真实手机流程。

| 工作包 | 阶段／关联 Tickets | 可演示产物 | 依赖与完成门槛 |
|---|---|---|---|
| W01 身份与基础工程 | M1；T01～T02、T05 | 注册、邮箱验证、登录保持、找回、退出、换号清理 | 账号 API、数据库迁移、邮件实际投递；断网令牌过期不阻断已登录学习 |
| W02 课程制作与装入 | M0/M1；T03～T04 | 首单元与整册包、来源校验报告、逐课就绪清单 | 先做首单元便于端到端验证；M0 完成需第一册整册核对 |
| W03 普通听说练 | M1；T06～T12 | 听读、锁屏、点词短语、三种跟读、三个答案入口、首次完成 | 飞行模式、无麦克风、无 AI Key；跟读不录音 |
| W04 复习与可信记录 | M1；T13～T16、T43～T49 | 轮次、复核、L2、80%、计划、颜色、维护期 | 规则例子、崩溃单次结算、推荐与负担分离、定义迁移 |
| W05 数据保护与 M1 交付 | M1；T17 | 手动备份、换号恢复、升级失败恢复、删除保护 | 恢复活跃轮和额度；无密钥；真实手机首课与次日复习 |
| W06 服务能力实验 | M2 前置；T50～T55 | 五家真实接入报告、模型／能力／价格注册表 | 不等待完善所有语音 UI 才发现厂商不支持；不阻塞 M1 试学 |
| W07 AI 设置与预算 | M2；T18、T50～T55 | 两类选择、五家凭据槽、独立测试、预算预留 | 真 Key 测试；退出／删数据清钥；本机直连；并发预算准入 |
| W08 发音与自动判断 | M2；T19～T21、T25、T42 | 可信粒度反馈、离线讲解、语义判断、遮盖复述 | 识别不冒充评测；无结果可自评；迟到不覆盖 |
| W09 实时对话与回顾 | M2；T22～T24、T26 | 两家十轮对话、打断、六类帮助、文本建议、开口估计 | 连续语音打断、回声、预算结束与录音停止真机通过 |
| W10 故障修复与交付 | M3 | P0 全量回归、个人安装包、可恢复数据 | M1 45＋M2 17 项全部通过，不以部分降级冒充完成 |
| W11 后续增强 | P1；T27～T36、T57～T58 | 第二至四册及 PRD 的其他增强 | 逐册 M0；前册历史保留；跨册共享策略先决策 |
| W12 后续教材与同步 | P2；T37～T38、T56 | 其他教材包、拍照、云同步 | 另行定义同步冲突、权限与数据政策；首版只预留结构 |

T39～T41 是此前已撤销的通用多教材任务，不复活为 M1。T50～T55、T56～T58 来自当前云端新增范围。工作包编号是依赖组织，不是未经估算的工期承诺。

M2 实验使用用户在实际 App 填写的 Key；本次架构编写没有读取或索要任何服务商密钥，也没有发起收费调用。

## 4. 测试层次与故障注入

纯 Kotlin 规则测试覆盖固定时间、结果优先级、单调参照、目标分母、L2 和 180／365 日推演；属性检验验证“帮助更多不会结果更好”“同命令不重复结算”“移出不改变分母”等不变量。

Room 设备测试使用真实事务和约束，注入进程终止、磁盘满、写失败、并发命令；不能只用内存假仓储来证明崩溃恢复。迁移测试从每个受支持旧 schema 和含活跃轮次的样本升级，并核对删除代际与备份恢复。

音频用真机验证耳机、扬声器、蓝牙、来电、锁屏、切后台、权限中途撤销和省电；模拟器测试不能代替这些门槛。AI 先用脱敏协议 fixtures 验证解析和旧结果隔离，最后用真实服务验证能力、用量与延迟；fixtures 不证明服务真实可用。

后端接口测试覆盖验证码一次消费、唯一性、令牌轮换复用、枚举防护、限流、邮件投递失败和删除幂等。验证码邮件不向未授权外部对象发送测试消息；使用开发测试邮箱或本人明确授权的账号。

## 5. 性能与运维验收

| 维度 | 建议目标／方法 | 边界 |
|---|---|---|
| 本地交互 | p95 <100ms | 在约定真机与十倍预期事件量下测 |
| 首次本地声音 | p95 <300ms | 已装资料，不计外部网络 |
| 停止声音 | p95 <200ms | 测本机队列清理；不等于厂商取消即时完成 |
| 冷启动 | p95 <2s 到可用页 | 正常已装包，迁移／恢复另计 |
| 实时语音 | 分别测首字、首音、整轮、打断、失败率 | 两家、两种网络分别记录，不先承诺统一数字 |
| 大文件 | 流式解压／校验／导出，无无界内存 | 空间不足、损坏和用户取消均可恢复 |
| 数据耐久 | 全部事务中断点不产生半结算 | 同时验证 WAL、关闭／重开和迁移 |
| 账号服务 | 注册登录、邮件、限流、备份恢复演练 | 服务不可用不拖垮已登录 M1 |
| 长期容量 | 180／365日、低新增／每日3～4项／>300维护项 | 如实显示延期和退让，不引入自动毕业 |

以上是验收目标，不是本次已测数据。第一次真实两周试学记录流程负担；长期保持与维护容量需观察到相应阶段后评价。

## 6. 开发前决策清单

| 问题 | 默认建议 | 关闭方式 |
|---|---|---|

| 模型／价格／协议版本 | 逐家验证并固定 ProviderProfile | PV01～PV10 报告，不使用未核实模型名 |
| 不明费用如何确认 | 仅实际响应或官方可用记录校正；否则保留待确认 | 逐家证明用量路径，不能虚构查询接口 |
| 发音反馈粒度 | 只展示实证层级，没可靠结果不评分 | PV08 对照样本和人工听辨 |
| 第一册资料与离线声音 | 首单元先验，整册再过M0 | 完整资源、来源、哈希、边界和目标清单 |

| 跨册项目是否共享 | 暂不提前合并，保留identity和scope映射 | P1首册扩展前产品确认 |
